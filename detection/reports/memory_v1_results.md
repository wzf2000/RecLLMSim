> 所有实验均为 GPT-4o-mini，测试集 90 用户 / 6474 turns。

## 3. v1 的核心问题

### 3.1 MAE 异常：有记忆反而更高

v1 none (0.7722) 的 MAE 高于 no_memory (0.7634)，即加了记忆反而更差。根因分析：

- **no_memory 的高分偏置**：no_memory 预测 score=5 的比例高达 **86%**，而 gold 分布中 score=5 仅占 **45%**。这种极端偏置使得 no_memory 在 score=5 的大量样本上命中率极高，MAE 反而低。
- **有记忆后分布校准**：none(v1) 预测 score=5 比例降至约 44%（接近 gold），但这意味着之前 "猜 5 分猜对" 的那批样本现在被纠正了，MAE 反而上升。
- **结论**：MAE 在此任务上被高分偏置严重干扰，相关性指标（Pearson/Spearman/Kappa）才是真实能力的体现。有记忆的 Pearson 为 0.2227，显著高于无记忆的 0.1690。

### 3.2 Oracle 更新无效

per_session_oracle (0.2206) 与 none (0.2227) 几乎相同（差 < 0.002），说明 v1 的 update prompt 无论真实标签还是预测标签都产生几乎相同的更新结果。原因：

- **记忆饱和**：平均历史 12.3 个 sessions，初始记忆已充分覆盖用户模式，单个新 session 无法带来实质更新
- **prompt 保守性**：update prompt 倾向于保持现有记忆不变
- **v1 内容同质化**：见 §3.3

### 3.3 Memory 内容质量差

人工检查 v1 memory 内容，发现 `high_satisfaction_patterns` 和 `dissatisfaction_patterns` 字段高度同质化，如：
- "提供详细步骤"（几乎所有用户都有）
- "回复要具体实用"
- "内容要有组织性"

这类泛化描述对所有用户都成立，无法体现个性化差异。分析时发现：**只有 33% 的预测 analysis 实际引用了记忆内容**，说明模型在推理时几乎忽略了所提供的记忆。
